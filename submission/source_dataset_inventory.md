# Source dataset inventory

Prepared for the STATS 401 final submission. This maps every dataset the project uses to its
**redistribution status** and its **location**, so the grader can obtain or verify each input.
All provenance here is taken from the committed manifests (`data/source_manifest.json`,
`data/analysis_manifest.json`, and the Phase-2 manifests) at release `main = aa2b494`.

## Legend

- **In repo (processed)** — cleaned/derived file committed under `data/processed/` or `data/display/`.
- **In repo (provenance)** — a manifest with provider, URL, licence and content hash is committed, even where the large binary is not.
- **External (gitignored)** — large source binary excluded by `.gitignore`; rebuilt by `scripts/acquire_data.py` or re-downloaded from the provider URL.
- **Reproducible** — regenerated by a committed script from the above.

## 2. Cleaned / processed / derived datasets (all committed)

`data/processed/` holds **37 committed analytical outputs**, including the current-period results
(`city_access_summary.json`, `district_access_metrics.csv`, `metro_access_points.csv`,
`metro_isochrone_10min.geojson`), the standardized temporal series
(`metro_access_temporal_{city,district,events,counterfactual}.csv`), urban dimensions
(`urban_dimensions_{city,district}.csv`), the audited Phase F1 overlap
(`transit_bazaar_overlap_{city,district}.csv`), sensitivity tables
(`walking_speed_sensitivity.csv`, `population_surface_sensitivity.csv`), and diagnostics.
`data/display/` holds the OSM metro-line snapshot and its provenance. The browser-ready typed
copies live in `site/data/` (23 files), each recorded in `site/data/manifest.json` with a content hash.

## 5. Redistribution status summary

- **OSM-derived processed files** — committed and redistributable under ODbL (attribution retained on the site).
- **SIAT-derived processed file** — committed and redistributable under CC BY 4.0 (attribution retained).
- **WorldPop raster** — redistributable under CC BY 4.0 **but excluded from Git** for size; provide via the provider URL or the owner's archive. SHA256 committed for verification.
- **OSM walk-network GraphML** — ODbL, excluded for size; re-pullable via `acquire_data.py`.
- **No secrets, credentials, or licence-restricted archives** are committed or required.

## 6. What the project owner must supply for a "raw files" upload (if the course requires it)

GitHub carries all **cleaned/processed** datasets and all **provenance + hashes**. If STATS 401
requires the raw/original binaries as a separate archive, the owner should provide **one archive**
containing the two gitignored source caches:

1. `data/external/uzb_pop_2026_CN_100m_R2025A_v1.tif` (WorldPop raster, SHA256 `bfc656b8…`)
2. `data/external/tashkent_walk_network.graphml` (OSM walk network)

and, optionally, the derived `data/external/population_cells.parquet` (SHA256 `948871e5…`).
Each can instead be regenerated from the committed scripts and provider URLs. **These files are
not present in this build environment** (they are gitignored and the original caches are not here),
so they cannot be attached from this session — they must come from the owner's original environment
or a fresh `acquire_data.py` run with network access to the providers.
